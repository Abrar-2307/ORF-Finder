# ORF-Finder

A beginner bioinformatics project built with Python for identifying Open Reading Frames (ORFs) from DNA sequences.

## What it does
- Takes a DNA sequence as input
- Searches for start and stop codons
- Identifies possible Open Reading Frames (ORFs)

## Why I built it
I built this project to practice Python programming and apply programming concepts to bioinformatics.

## Technologies
- Python
